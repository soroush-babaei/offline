# 🤖 Telegram Auto-Reply Bot

## us English

### 🧠 Problem
Messages often go unanswered when you are offline or don't have the time to reply immediately.

### ⚙️ Solution
A powerful Python-based Telegram bot that automatically manages and replies to messages, ensuring no user is left waiting.

### ✨ Features
- ✅ **Auto-Reply:** Instant response to all incoming messages.
- 🔒 **Secure & Simple:** Designed with clean code and security principles in mind.
- 🌐 **Flexible:** Supports direct connection or proxy usage.
- 🐍 **Python-Based:** Lightweight, fast, and easily extensible.

### 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/soroush-babaei/Telegram-Auto-Reply-Bot.git
   cd Telegram-Auto-Reply-Bot

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt

3. **Configuration:**
   ```bash
   api_id='Put Your API_ID'
   api_hash='Put Your API_HASH'
   
4.**Run the bot:**
  ```bash
  python Offline_replayer.py
   ```
